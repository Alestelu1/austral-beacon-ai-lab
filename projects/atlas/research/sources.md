# Research Sources — End of the World Atlas

## Purpose

This file tracks verified sources for the End of the World Atlas Knowledge Base.

Sources should support:

- geographic accuracy
- coordinates
- historical context
- maritime routes
- Antarctic logistics
- scientific references
- editorial claims
