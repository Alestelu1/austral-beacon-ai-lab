# Austral Beacon — Agent Architecture

## Purpose

This document defines the initial AI agent architecture for the Austral Beacon ecosystem.

These agents are intended to evolve through:

* Alura ONE AI
* LangChain
* n8n
* Gemini
* Kiro Bootcamp
* Future hackathons
* Production deployments

---

# Agent 1 — Atlas Agent

## Mission

Serve as the geographic intelligence layer of the ecosystem.

## Knowledge Sources

* End of the World Atlas MDX files
* Entity Graph
* Geographic datasets
* Structured metadata

## Responsibilities

* Geographic explanations
* Route descriptions
* Entity relationships
* Historical and geographic context
* Atlas search

## Example Questions

* What is Puerto Williams?
* Explain the route to Cape Horn.
* How is Diego Ramírez connected to Antarctica?

---

# Agent 2 — Antarctic Pulse Agent

## Mission

Monitor science, climate, logistics and Antarctic activity.

## Knowledge Sources

* Atlas entities
* Scientific feeds
* Antarctic news
* Climate and logistics data

## Responsibilities

* Scientific summaries
* Climate monitoring
* Logistics monitoring
* Dashboard generation
* Alert generation

## Example Questions

* What scientific activity is occurring in Bahía Fildes?
* What climate factors affect Antarctic operations?

---

# Agent 3 — Antarctica Begins Agent

## Mission

Act as a gateway and logistics assistant.

## Knowledge Sources

* Atlas entities
* Route data
* Logistics documentation
* Antarctic gateway information

## Responsibilities

* Route planning
* Gateway explanations
* Logistics recommendations
* Infrastructure explanations

## Example Questions

* How do I reach the Antarctic Peninsula?
* What is the role of Punta Arenas?

---

# Agent 4 — Travel Storytelling Agent

## Mission

Transform Atlas knowledge into visual and editorial content.

## Knowledge Sources

* Atlas entities
* Historical references
* Geographic narratives

## Responsibilities

* Social posts
* Editorial articles
* Travel storytelling
* Content repurposing

## Example Questions

* Create a post about Cape Horn.
* Explain Puerto Williams for social media.

---

# Long-Term Vision

The four agents should eventually operate together:

Atlas Agent
→ Geographic knowledge

Antarctic Pulse Agent
→ Science and monitoring

Antarctica Begins Agent
→ Logistics and gateways

Travel Storytelling Agent
→ Content and outreach

Together they form the core intelligence layer of Austral Beacon.
