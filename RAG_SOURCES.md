# Austral Beacon AI Lab — RAG Sources

This document tracks sources that may be used later for RAG systems, knowledge bases, editorial research and atlas-style documentation.

The goal is to build a reliable source library for:

- End of the World Atlas
- Antarctic Pulse
- Pulso Antártico
- Austral Beacon
- Antarctica Begins
- End of the World Travel
- Fin del Mundo Travel

RAG sources should be evaluated before being used in public-facing outputs.

---

## Source Intake Principles

Every source should preserve:

- Original title
- Source URL
- Publisher / institution
- Date if available
- Author if available
- Source type
- Geographic tags
- Topic tags
- Summary
- Credibility level
- RAG readiness
- Verification notes

---

## Source Quality Levels

Use these labels:

1. **Primary source**
2. **Official institutional source**
3. **Scientific / academic source**
4. **Reputable media source**
5. **Local specialist source**
6. **Tourism / commercial source**
7. **User note**
8. **Unverified / needs review**

## Verification Checklist

Before using a source in a public article or dashboard:

- [ ] Is the URL preserved?
- [ ] Is the publisher identified?
- [ ] Is the date known?
- [ ] Is the claim still current?
- [ ] Is the source official, academic, reputable, local, commercial or unverified?
- [ ] Does the source contain facts, opinions or promotional material?
- [ ] Does the source require translation?
- [ ] Is the source suitable for RAG?
- [ ] Does it need manual review?
- [ ] Does it align with the project's documentary/cartographic identity?
