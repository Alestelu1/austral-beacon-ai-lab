# Base Científica Profesor Julio Escudero

Instalación científica chilena operada por el Instituto Antártico Chileno (INACH) en la península Fildes, Isla Rey Jorge, islas Shetland del Sur.

La base se modela como infraestructura científica. La dotación, capacidad disponible, campañas, equipamiento temporal y condiciones operativas deben verificarse con información vigente de INACH y no se consideran hechos estables del Travel Assistant.
