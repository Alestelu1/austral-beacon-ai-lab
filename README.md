

# Austral Beacon AI Lab

AI, automation, RAG and agentic workflow laboratory for Austral Beacon Media Network, End of the World Atlas, End of the World Travel, Antarctic Pulse, Antarctica Begins, and related southern / Antarctic media projects.

This repository is an external technical memory for strategy, architecture, prompts, workflows, RAG sources, experiments, dashboards and learning logs.

## Core Purpose

Build reusable AI infrastructure for a documentary, cartographic and editorial media ecosystem focused on:

- Patagonia and southern Chile
- Puerto Williams, Cape Horn and Tierra del Fuego
- Strait of Magellan, Beagle Channel and Antarctic gateway routes
- Antarctic logistics, science, travel and exploration
- Lighthouses, maps, routes and southern infrastructure
- AI-assisted editorial workflows and RAG knowledge systems

## Main Projects

### Austral News Radar v0.1

A first AI workflow for detecting, summarizing, classifying and preparing editorial content from southern / Antarctic news sources.

### End of the World Atlas Knowledge Base

A RAG-ready knowledge base for places, routes, maps, historical documents and geographic explainers.

### Antarctic Pulse Monitor

A monitoring system for polar science, Antarctic signals, logistics, expedition news and environmental updates.

### Austral Dispatch Briefing

A briefing/newsletter workflow for short editorial updates in English and Spanish.
