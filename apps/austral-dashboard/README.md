# Austral Beacon Media Intelligence Dashboard

**Production deployment:** https://austral-beacon-media-dashboard.vercel.app

Austral Beacon Media is the parent brand for a serious southern geography, Antarctic routes, and editorial intelligence ecosystem. Austral Beacon AI Lab is the technical lab and prototype area responsible for this first static dashboard. Intelligence Dashboard is the product name for the browser-openable workspace.

## Files

- `index.html` contains the dashboard markup and public-facing brand hierarchy.
- `styles.css` contains the dark navy, ice, and amber responsive visual system.
- `app.js` contains sample data rendering, queue filters, mobile navigation, and checklist progress.
- `README.md` documents the dashboard, deployment, scope, and next iteration path.

## How to Run Locally

Open `index.html` directly in a browser from `apps/austral-dashboard/`.

No build step, package manager, framework, or external dependency is required. The dashboard is plain HTML, CSS, and JavaScript.
