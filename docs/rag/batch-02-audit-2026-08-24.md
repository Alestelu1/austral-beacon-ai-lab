# Batch 02 Audit — 2026-08-24

## Scope

Final structural audit of the southern Magallanes / Ruta de los Parques knowledge layer before considering merge of PR #9.

- Atlas promotion queue

## Findings

### 1. Referential integrity

**Finding:** `southern-magallanes-connectivity-graph.json` contained a prohibited edge targeting `argentina` without a corresponding graph node.

**Action:** added canonical `argentina` country node and incremented graph version to `v1.1`.

**Status:** resolved.

### 2. Atlas administrative readiness

**Finding:** the Atlas promotion queue marked `paso_san_sebastian` as `administrative_metadata: ready`, while the canonical entity currently records region/province but not commune. `pn_alberto_de_agostini` was also marked ready despite only regional administrative metadata being canonical.

**Action:** changed both records to `partial` and added explicit completion warnings.

**Status:** resolved.

### 3. Geospatial promotion queue consistency

**Finding:** the authoritative-source registry geometry queue did not include all high-priority Atlas records, especially protected areas and border/crossing entities.

**Action:** added Primera Angostura, San Sebastián, Bellavista, Yendegaia, Alberto de Agostini and Cabo de Hornos to the geometry queue.

**Status:** resolved.

### 4. Verification date

**Finding:** the geospatial registry retained `checked_at: 2026-08-23` even though this audit and current authoritative-source review are being performed on 2026-08-24.

**Action:** updated registry `checked_at` to `2026-08-24`.

**Status:** resolved.

## Controls that passed

- `puerto_williams` uses the same canonical ID across southern-Magallanes and Antarctic graphs.
- Shared entity IDs do not automatically transfer operational edges between graphs.
- Vicuña–Yendegaia remains explicitly modeled as under construction.
- No canonical continuous road edge exists from Ruta Y-85 to Puerto Williams.
- Puerto Williams–Puerto Toro connectivity remains classified as subsidized isolated-zone transport, not a tourism product.
- Dynamic ferry schedules, fares, border openings and road conditions remain outside Atlas core fields.
- Atlas geometry remains gated behind producer, dataset/layer, CRS and retrieval-date provenance.
- Protected-area access remains separate from public-use infrastructure availability.
