## Criterio de cierre del Travel Assistant

El Travel Assistant se considerará listo para cambiar de prioridad cuando pueda:

- recibir una consulta turística;
- recuperar información desde fuentes verificadas;
- responder con referencias o trazabilidad;
- manejar correctamente ausencia de evidencia;
- ejecutar pruebas básicas;
- desplegarse o demostrarse mediante una interfaz funcional;
- contar con documentación suficiente para continuar sin depender de Kiro.
