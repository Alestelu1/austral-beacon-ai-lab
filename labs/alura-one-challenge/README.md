# Alura ONE Challenge — Austral Knowledge Assistant

Repositorio de trabajo para el MVP del Challenge de Alura ONE AI, integrado inicialmente dentro de Austral Beacon AI Lab.

## Objetivo

Construir un asistente documental capaz de consultar fuentes confiables del extremo austral de Chile y la Antártica, recuperar fragmentos relevantes y responder con trazabilidad de fuentes.

## Alcance inicial

- Ingesta de documentos seleccionados.
- Preparación de metadatos.
- División en fragmentos.
- Embeddings y recuperación semántica.
- Respuestas con contexto y citas.
- Interfaz mínima para demostración.

## Fuera del MVP

- Knowledge Graph completo.
- Automatización editorial integral.
- Múltiples agentes especializados.
- Indexación masiva de todo el archivo documental.
- Dependencia obligatoria de Oracle OCI.

## Relación con Austral Beacon AI Lab

Este Challenge funciona como módulo experimental del laboratorio. Las reglas editoriales, territoriales y documentales se basarán en la documentación central de Austral Beacon AI Lab, pero la implementación del MVP permanecerá separada del proyecto del hackathon de CódigoFacilito/Kiro.
