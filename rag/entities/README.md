# RAG Entities

Store extracted entities from official documents and source material.

Entity examples:

- Places: Puerto Williams, Cabo de Hornos, Isla Navarino, Punta Arenas.
- Routes: Canal Beagle, Estrecho de Magallanes, Ruta Vicuña–Yendegaia.
- Organizations: SERNATUR, CONAF, INACH, Armada de Chile, INE.
- Protected areas: Parque Nacional Cabo de Hornos, Parque Nacional Alberto de Agostini, Reserva de la Biosfera Cabo de Hornos.

Use these outputs to support End of the World Atlas, End of the World Travel, Antarctica Begins and future AI agents.
