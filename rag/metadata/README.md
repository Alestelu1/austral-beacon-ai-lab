# RAG Metadata

Store JSON or YAML metadata records for each source document.

Recommended fields:

```yaml
title:
source_url:
publisher:
author:
date:
source_type:
language:
geographic_tags:
topic_tags:
related_projects:
credibility_level:
rag_readiness:
verification_notes:
local_file:
```

Metadata should preserve the original source URL and publication context so future agents can cite and verify sources.
